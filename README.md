# Bunny Girl Senpai: Dreams Beyond Reality

A standalone browser-based visual novel fan project.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No build step or server is required.
3. Choose **Start New Story**. Progress and settings save in localStorage when the browser permits it.

## Controls
- Click/tap the dialogue panel or use **Next** to advance.
- Use **Journal** for relationship stats, clues, and promises.
- **Backlog**, **Save**, **Load**, **Settings**, **Pause**, and **Chapters** are available in play.
- Keyboard: Space or → advances dialogue; Escape closes a modal.

## Project files
- `index.html` — interface and layout
- `style.css` — responsive styling and CSS-generated atmospheric scene art
- `characters.js` — character profiles
- `story.js` — chapter/scene/choice data
- `script.js` — dialogue engine, branching, relationship variables, settings, saves, journal, and endings

## Notes
This is an unofficial fan-project prototype with original story scenes. No copyrighted character images or music are bundled. Audio volume settings are included as UI settings, but ambient music and SFX are not bundled. The game includes five ending paths and an epilogue. Saves are browser-local, not cloud synced.
